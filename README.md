🪙 First-to-Three Coin Flipper

This is a simple coin-flipping game where you and a friend pick heads or tails, and the game keeps flipping until one side reaches three wins first.

🎮 How It Works

The program simulates coin flips
Each flip counts as a point for the winning side
The first side to 3 wins takes the game

💡 Why I Made This

I wanted to build something small to get started with Python, and this turned into a fun  way to settle random debates or make decisions.

🛠️ How to Run
```bash
python coin_flipper.py
```

Run the script:

python coin_flipper.py
Follow the prompts and play!

⚠️ Disclaimer
This will not guarantee you win arguments… but it can help :-)
